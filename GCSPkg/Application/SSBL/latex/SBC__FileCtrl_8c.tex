Locates all handles that support the EFI Simple File System Protocol. 

This function queries the UEFI firmware to find all handles that implement the {\ttfamily g\+Efi\+Simple\+File\+System\+Protocol\+Guid}. These handles can be used to access EFI-\/compatible file systems such as FAT32 partitions.


\begin{DoxyParams}[1]{Parameters}
\mbox{\texttt{ out}}  & {\em handle} & Pointer to a buffer that receives the array of EFI handles. The buffer is allocated by the UEFI boot services.\\
\hline
\end{DoxyParams}
\begin{DoxyReturn}{Returns}
UINTN
\begin{DoxyItemize}
\item Number of handles found that support the Simple File System Protocol.
\item Returns 0 if no handles are found or if an error occurs.
\end{DoxyItemize}
\end{DoxyReturn}
\begin{DoxyNote}{Note}

\begin{DoxyItemize}
\item The caller must ensure that {\ttfamily handle} is a valid pointer to receive the handle array.
\item The returned handle array must be freed using {\ttfamily Free\+Pool()} when no longer needed.
\item This function is typically used during boot-\/time file access (e.\+g., loading FSBL/\+SSBL).
\end{DoxyItemize}
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
If the protocol is not found, the function logs an error and returns 0.
