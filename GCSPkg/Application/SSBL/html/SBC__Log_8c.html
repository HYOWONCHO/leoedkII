Formats a variable argument list into a Unicode string buffer, handling NULL CHAR16* arguments safely.

This function parses the format string and uses arguments from VaListMaker to construct a formatted Unicode string in LogBuf. It performs NULL checks for s specifiers to prevent hard faults.

Build a formatted Unicode message containing a hexadecimal representation of binary data.

Example usage:

CHAR16 Msg[256];
SBC_BuildHexFormattedMessage(KeyData, KeyLen, L"Public Key: %s", Msg, sizeof(Msg));
SBC_BuildHexFormattedMessage
EFI_STATUS SBC_BuildHexFormattedMessage(IN CONST VOID *PubKey, IN UINTN PubKeySize, IN CONST CHAR16 *FormatString, OUT CHAR16 *OutMsg, IN UINTN OutMsgBytes)
Build a formatted Unicode message containing a hexadecimal representation of binary data.
Definition SBC_Log.c:337

The resulting message will contain the prefix text defined by the format string, followed by the converted hexadecimal string of PubKey.

Parameters
[in]PubKeyPointer to the binary data (e.g., public key or hash) to be converted.
[in]PubKeySizeSize of the binary data buffer in bytes.
[in]FormatStringUnicode (CHAR16) format string that defines how the final message should be constructed. Example: L"Key Digest: %s".
[out]OutMsgPointer to a caller-allocated buffer that receives the formatted message. The buffer must be large enough to store the formatted text and the hexadecimal string.
[in]OutMsgBytesSize of the output buffer OutMsg, in bytes.
Return values
EFI_SUCCESSThe formatted message was successfully created.
EFI_INVALID_PARAMETEROne or more parameters are NULL or invalid.
EFI_BUFFER_TOO_SMALLThe output buffer is too small for the generated message.
EFI_OUT_OF_RESOURCESMemory allocation or internal buffer operation failed.
