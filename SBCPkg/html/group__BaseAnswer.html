Validate the device authentication answer using the provided key.

Parameters

[in]answerPointer to the answer buffer received from the device or host.
[in]answerlLength of the answer buffer, in bytes.
[in]keyPointer to the security key used for validation.
[in]keylenLength of the key buffer, in bytes.
[in]ischeckBoolean flag indicating whether to perform strict validation.
  • TRUE : Perform full verification (compare with expected digest)
  • FALSE: Do not perform verification, just copy the base-answer in proveded buffer

SBCFAILValidation failed (mismatch or computation error).
SBCNULLPOne or more input pointers are NULL.
SBCIODevice I/O or communication error occurred.
SBCINVPARAMInvalid parameter or key length.
Note
This function may internally use a cryptographic algorithm (e.g., AES, HMAC, or SHA) depending on the implementation.
