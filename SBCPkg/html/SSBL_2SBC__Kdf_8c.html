SBCStatus SBC_HKdfSha256 ( kdf_t *  k,
LV_t *  out 
)

Derive a cryptographic key using HKDF with SHA-256.

Derive SHA256 HMAC-based Extract key Derivation Function (HKDF).

Author
leoc (5/20/25)
Parameters
[in]kPointer to the kdf_t structure
[out]outPointer to buffer to receive the HKDF
Returns
SBCStatus
Parameters
[in]kPointer to a kdf_t structure containing HKDF parameters:
  • salt — Optional random salt value.
  • ikm — Input Keying Material (base key input).
  • info — Optional context/application-specific information.
  • len — Desired length of the output key.
[out]outPointer to an LV_t structure that receives the derived key. The buffer must be allocated to accommodate the requested length.
Return values
SBCOKKey derivation completed successfully.
SBCFAILHKDF computation failed (e.g., HMAC operation failure).
SBCNULLPOne or more input pointers are NULL.
SBCINVPARAMInvalid HKDF parameters (e.g., zero-length key or salt).
SBCCRYPTOSHA-256 or HMAC computation error occurred.
