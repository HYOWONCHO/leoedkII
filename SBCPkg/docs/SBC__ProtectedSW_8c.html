Re-encrypt (re-crypto) a protected software image using a new key set.

Parameters
[in]handlePointer to the SBC protected software context or partition handle. Identifies the target partition containing the software data.
[in]ofsOffset or index of the software block to re-encrypt. Typically corresponds to the node offset within the partition.
[in]sw_secret_keyPointer to the main AES key (e.g., 256-bit key) used for re-encryption. Must be SBC_AT_RP_KEY_LEN bytes long.
[in]sw_mig_keyPointer to the migration key used for transitioning to a new key version or hierarchy.
May be NULL if only a single key is used.
Return values
SBCOKRe-encryption successfully completed.
SBCFAILRe-encryption failed due to data corruption or key mismatch.
SBCNULLPOne or more input pointers are NULL.
SBCINVPARAMInvalid offset, key length, or partition context.
SBCCRYPTOCryptographic engine or AES-GCM processing error.
SBCIOI/O failure during read or write to the secure partition.
Parameters
[in]handleProtected software partition handle
[in]ofsOffset of the software node to re-encrypt
[in]sw_secret_keyPrimary software encryption key (AES-256)
[in]sw_mig_keyMigration key for key rotation (optional)
