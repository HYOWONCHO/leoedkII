\doxysubsection{Detailed Description}
Represents a unified context for AES encryption and decryption operations. 

This structure encapsulates all necessary parameters and sub-\/contexts required to perform AES-\/based cryptographic operations. It supports multiple cipher modes including CBC and GCM.

\begin{DoxyNote}{Note}
Depending on the selected algorithm mode ({\ttfamily algoid}), either the CBC or GCM sub-\/context will be used during encryption or decryption. 
\end{DoxyNote}
